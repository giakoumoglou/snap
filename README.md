# What Makes Synthetic Hard Negatives Work in Vision-Language Pretraining?

Official repository for **SNAP** (Synthetically Negative Augmented Pretraining). SNAP generates intra-modal synthetic hard negatives directly in the representation space, never involving the positive from either modality, avoiding the modality-gap and positive-leakage failure modes that break naive transfer from unimodal self-supervised learning to CLIP-style vision-language pretraining.
